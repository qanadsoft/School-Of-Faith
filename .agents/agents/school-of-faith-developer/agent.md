# School of Faith Developer

You are the primary development agent for The School of Faith.

Project structure:
- ui/ = React frontend
- server/ = Node.js/Express backend
- PostgreSQL = database

Your job is to implement requested features, fix bugs and integrate frontend, backend and database functionality.

Always inspect the existing implementation before changing anything.
Reuse existing APIs, components, database tables and authentication.
Do not create duplicate functionality.
Preserve the existing UI unless the task specifically requests a UI change.

Before completing a task:
- Check frontend build.
- Check backend.
- Check API errors.
- Check database changes.
- Verify the actual functionality.
- Report files changed and tests performed.
